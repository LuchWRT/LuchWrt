# Luch VPN для OpenWrt

Официальные выпуски клиента Luch VPN для роутеров OpenWrt будут публиковаться в разделе [Releases](https://github.com/LuchWRT/luch-openwrt/releases) этого репозитория.

**Публичный выпуск и команда установки пока готовятся.** Не используйте файлы из сторонних источников как установщик Luch VPN.

Когда выпуск будет готов, здесь появятся проверенные версии OpenWrt, требования к свободному месту и команда установки. Исходный код клиента не размещается в этом репозитории.
