# LuchWrt

**Простой клиент Xray/VLESS для OpenWrt от [Luch VPN](https://luch.one).** Подключение устройств домашней сети, выбор локации и обновление конфигураций — через понятное меню в SSH.

## Установка

Подключитесь к роутеру по SSH от имени `root` и вставьте одну команду:

```sh
f=$(mktemp) && wget -T 60 -q -O "$f" 'https://raw.githubusercontent.com/LuchWRT/LuchWrt/4131689ca35c5abe98665da9f2599223275f0523/install-v1.2.4.sh' && [ "$(sha256sum "$f" | cut -d ' ' -f 1)" = '80e7ff2cdea5d037a55ae4306c3f4036dac10661e9b4b738bf5b7b9ea84cb36d' ] && sh "$f"; result=$?; rm -f "$f"; [ $result -eq 0 ]
```

Установщик определит версию и архитектуру OpenWrt, проверит файлы выпуска и доступное место до изменения сетевых настроек. Нужны работающий HTTPS и **80 МиБ свободного места**. После установки меню откроется само: выберите язык. Позднее меню можно открыть командой `luch`.

## Что умеет LuchWrt

- **Удобное управление:** добавление подписки, выбор локации, проверка связи и обновление из меню; понятный индикатор во время ожидания.
- **Полный Xray JSON:** сохраняет правила маршрутизации, DNS, прямые подключения и балансировку полученной конфигурации.
- **Автоматическое обновление локаций:** ежедневно в 2:00 по UTC+3; вручную — в любой момент.
- **Резервный переход:** при сбое выбранной локации проверяет следующие. Если ни одна не работает, снимает свои сетевые правила и возвращает обычный выход через роутер.
- **Проверяемые обновления:** сверяет подпись и контрольные суммы; предыдущая версия сохраняется для отката.
- **Русский и английский интерфейс:** язык выбирается при первом запуске и меняется в меню.

## Меню

```text
Luch VPN  ·  OpenWrt
Управление подключением
  1  Статус
  2  Добавить или заменить подписку
  3  Сменить локацию
  4  Обновить локации и проверить VPN
  5  Проверить связь через VPN
Программа и помощь
  6  Сведения о роутере
  7  Где получить подписку
  8  Проверить новую версию
  9  Установить новую версию
 10  Язык  [RU]
  0  Выход
Выберите номер:
```

Справка, статус, диагностика и результаты проверок открываются отдельным экраном. Введите `0`, чтобы вернуться в меню. В форме подписки и при выборе локации `0` тоже возвращает назад без изменения настроек.

## Проверенная совместимость

Выпуск **[v1.2.4](https://github.com/LuchWRT/LuchWrt/releases/tag/v1.2.4)** испытан на следующих официальных образах OpenWrt в QEMU. Для каждой строки проверены установка из GitHub с подписью, запуск службы после перезагрузки и выбор точного пакета для версии и архитектуры. Xray-конфигурации и сетевые сценарии с отдельным LAN-клиентом ранее прошли на этих же точных целях.

| OpenWrt | Архитектура пакетов | Сетевой режим |
| --- | --- | --- |
| 21.02.7 | `x86_64` | `fw3` / iptables |
| 22.03.7 | `x86_64` | `fw4` / nftables |
| 23.05.6 | `x86_64` | `fw4` / nftables |
| 24.10.8 | `x86_64` | `fw4` / nftables |
| 24.10.8 | `aarch64_generic` | `fw4` / nftables |
| 24.10.8 | `arm_cortex-a15_neon-vfpv4` | `fw4` / nftables |
| 25.12.5 | `x86_64` | `fw4` / nftables |

Таблица указывает **точные проверенные сочетания** прошивки и архитектуры, а не все устройства с OpenWrt. Для установки также нужны совместимые системные пакеты, память и свободное место; установщик проверяет доступные условия на самом роутере.
