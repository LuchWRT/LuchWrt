# LuchWrt

**Удобный клиент Xray/VLESS для OpenWrt от команды [Luch VPN](https://luch.one).** Устанавливается одной командой, управляется через понятное меню в SSH и помогает поддерживать подключение устройств домашней сети без ручного редактирования больших конфигураций.

## Возможности

- **Управление из меню:** добавление подписки, выбор локации, проверка соединения и смена языка между русским и английским.
- **Полная конфигурация Xray:** клиент сохраняет правила маршрутизации, DNS, прямые подключения и балансировку из полученного JSON.
- **Актуальные локации:** ручное обновление из меню и ежедневное фоновое обновление в 02:00 по московскому времени.
- **Проверка реального подключения:** при сбое выбранной локации клиент пробует следующие; если все недоступны, снимает свои сетевые правила и возвращает обычный выход через роутер.
- **Аккуратные обновления:** файлы выпуска проверяются подписью и контрольными суммами, предыдущая версия остаётся для отката. Неиспользуемые старые версии удаляются.
- **Без лишних журналов:** фоновая служба и Xray не создают собственных файлов логов; сообщения интерактивного меню видны в терминале.

## Меню

```text
Luch VPN  ·  OpenWrt
Управление подключением
  1  Статус
  2  Добавить или заменить подписку
  3  Сменить локацию
  4  Обновить локации и проверить VPN
  5  Проверить связь через VPN
Программа и помощь
  6  Сведения о роутере
  7  Где получить подписку
  8  Проверить новую версию
  9  Установить новую версию
 10  Язык  [RU]
  0  Выход
Выберите номер:
```

При первом запуске предлагается выбрать русский или английский. Затем язык можно сменить в пункте `10`.

## Установка

Текущий выпуск — **[v1.0.1](https://github.com/LuchWRT/LuchWrt/releases/tag/v1.0.1)**. Однокомандная установка проверена для **OpenWrt 24.10.8 `x86_64`**. Нужны права `root`, доступ к HTTPS и не менее **200 МиБ свободного постоянного места**. Установщик проверит систему и файлы выпуска перед применением изменений.

Подключитесь по SSH к роутеру и выполните:

```sh
f=$(mktemp) && wget -T 60 -q -O "$f" 'https://github.com/LuchWRT/LuchWrt/releases/download/v1.0.1/bootstrap-ff19d5adeae0e074e5d90fe04dee8b1f9a730596ddb2e24db9595bea459cb44a.sh' && [ "$(sha256sum "$f" | cut -d ' ' -f 1)" = 'ff19d5adeae0e074e5d90fe04dee8b1f9a730596ddb2e24db9595bea459cb44a' ] && sh "$f"; result=$?; rm -f "$f"; [ $result -eq 0 ]
```

После установки запустите `luch`. Если установлена v1.0.0, обновление также доступно через пункт `9` меню или команду `luch-install -update`.
