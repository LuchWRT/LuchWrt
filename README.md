# Luch VPN для OpenWrt

Официальный клиент Luch VPN для роутеров OpenWrt. Он принимает подписки только с `subs.luch.one`. Исходный код клиента и закрытый ключ выпуска не размещаются в этом публичном репозитории; подписанные файлы доступны в [GitHub Releases](https://github.com/LuchWRT/LuchWrt/releases).

## Установка

Текущий выпуск — [v1.0.1](https://github.com/LuchWRT/LuchWrt/releases/tag/v1.0.1). **Публичная установка заявлена только для OpenWrt 24.10.8 `x86_64`** с работающим HTTPS и не менее **200 МиБ свободного постоянного места**. Эту цель проверили в QEMU; работу на всех моделях роутеров и других версиях OpenWrt пока не подтверждали. Установщик проверяет точную версию и архитектуру, свободное место, подписи и хэши до установки клиента.

Подключитесь по SSH к **роутеру** с правами `root` и вставьте одну команду:

```sh
f=$(mktemp) && wget -T 60 -q -O "$f" 'https://github.com/LuchWRT/LuchWrt/releases/download/v1.0.1/bootstrap-ff19d5adeae0e074e5d90fe04dee8b1f9a730596ddb2e24db9595bea459cb44a.sh' && [ "$(sha256sum "$f" | cut -d ' ' -f 1)" = 'ff19d5adeae0e074e5d90fe04dee8b1f9a730596ddb2e24db9595bea459cb44a' ] && sh "$f"; result=$?; rm -f "$f"; [ $result -eq 0 ]
```

После установки запустите `luch`, выберите язык и добавьте ссылку подписки. Для уже установленной v1.0.0 доступно обновление через пункт 9 меню или команду `luch-install -update`. v1.0.1 не создаёт собственных файлов журналов и отключает фоновые журналы Xray; при обновлении сохраняет предыдущую версию для отката.

Подписку можно получить в [Telegram Mini App](https://t.me/LuchVPN_bot) или [веб-приложении](https://app.luch.one/webapp). Подробнее о сервисе — на [luch.one](https://luch.one).
