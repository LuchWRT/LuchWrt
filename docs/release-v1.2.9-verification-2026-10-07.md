Подмена транспорта, локальная доставка новых пакетов и отключение TLS-проверки не использовались.

Для каждой строки подтверждены точный установленный слот, хэши всех восьми файлов, меню и ввод CRLF, отключение и включение, работа службы после настоящей перезагрузки, удаление клиента с сохранением заранее созданных посторонних настроек. Смена boot ID подтверждает перезагрузку. Образы и ARM-ядра сверены с официальными каталогами SHA-256; каталоги повторно получены 7 октября.

## Обновление установленного клиента

На OpenWrt 25.12.5 `arm_cortex-a15_neon-vfpv4` переход с универсального v1.2.8 на точный v1.2.9 прошёл **9/9 проверок**. Сохранены HWID, английский язык, ручное отключение и предыдущий слот для отката. После первой перезагрузки отключённая служба не запускалась; после включения из меню и второй перезагрузки подтверждены действующая служба и автозапуск.

Исходный v1.2.8 установлен из прежнего неизменённого подписанного набора локально, поскольку адрес latest уже выдавал v1.2.9. Все старые файлы и метаданные дополнительно сверены с опубликованными файлами v1.2.8. Сам переход на v1.2.9 выполнен новой публичной командой через GitHub.

[Машинный отчёт обновления](compatibility/2026-10-07-v1.2.9-upgrade.json), SHA-256: `cefe96d72096b828fef33fc0460eadf81340e84d332e20bb90e97f0c9b029cbb`.

Для этого перехода следует повторить новую команду из README. Старое меню v1.2.8 выбирает универсальный пакет; равная версия повторно не устанавливается.

## Границы испытаний

Использованы QEMU, 512 МиБ RAM и диск с корневым разделом 512 МиБ, синтетическая конфигурация без живой подписки. Успех 17 установок подтверждает перечисленные сценарии; полный набор сетевых сценариев не испытывался на всех 17 системах. Отдельные [испытания TCP, UDP, DNS и PBR](compatibility/2026-10-05-v1.2.8-lan.json) относятся к опубликованному v1.2.8 на ARM64 и ARMv7. Физические роутеры, малые объёмы RAM и flash, IPv6 и живые VPN-серверы этим прогоном не проверены.

До публикации [17 точных пакетов](compatibility/2026-10-05-v1.2.9.json) проверены на локальном подписанном наборе; отдельно прошли регрессионные тесты семи исправлений, race, vet, проверка зависимостей и шесть сценариев отката с procd и Xray. Публичные испытания 7 октября дополняют эти результаты. Исходный код и подписанные файлы выпуска между ними не менялись.
