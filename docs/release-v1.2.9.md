# Кандидат LuchWrt v1.2.9

Для всех 17 подтверждённых сочетаний OpenWrt и архитектуры подготовлены отдельные подписанные пакеты. Единая команда автоматически выбирает точный пакет; для остальных систем сохранены восемь подписанных пакетов семейств процессоров.

Исправлены семь воспроизводимых ошибок: отменённый запрос мешал откату Xray после ошибки сохранения; сбой подготовки обновления геоданных блокировал исправный текущий набор; перенаправленный промежуточный каталог установки мог затронуть чужие файлы; новый обновлятор мог потерять закреплённый адрес выпусков; удаление разрушало действующую блокировку; повтор актуальной установки требовал место второго bundle; активный универсальный слот мешал выбрать появившуюся точную цель. Ошибки сети, подписи и несовпадение цели не разрешают fallback. Защита от понижения версии сохранена.

Все 17 окончательных exact-пакетов прошли установку, меню, проверку всех восьми артефактов, настоящую перезагрузку и удаление в QEMU. Переход с universal v1.2.8 на exact v1.2.9 сохранил язык, HWID, ручное отключение и предыдущий слот. Регрессионные проверки, race, vet и проверка зависимостей прошли; откат дополнительно проверен в шести сценариях с настоящими procd и Xray. Все 327 файлов GitHub сверены с зафиксированным локальным набором по именам, размерам и SHA-256.

Если установлен универсальный v1.2.8, для непосредственного перехода на точный v1.2.9 повторите новую команду установки из README. Старое меню v1.2.8 при обычном обновлении продолжает выбирать универсальный пакет своего семейства. Если старое меню уже поставило universal v1.2.9, переход на exact будет возможен в следующем более новом выпуске. Равная версия повторно не устанавливается.

Xray 26.3.27, геоданные и init-файлы побайтово сохранены из подписанного v1.2.8; соответствующий исходный архив Xray и лицензии включены. Эти испытания относятся к официальным виртуальным образам с 512 МиБ RAM и корневым разделом 512 МиБ. Работа физических моделей роутеров и живых VPN-серверов не подтверждается этими результатами. До публикации проверялся локальный подписанный пакет; настоящая команда GitHub для v1.2.9 повторяется после публикации.
