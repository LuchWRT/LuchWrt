# LuchWrt v1.2.9

[Выпуск опубликован 7 октября 2026 года](https://github.com/LuchWRT/LuchWrt/releases/tag/v1.2.9). Для 17 подтверждённых сочетаний OpenWrt и архитектуры подготовлены отдельные подписанные пакеты. Единая команда автоматически выбирает точный пакет; для остальных систем сохранены восемь подписанных пакетов семейств процессоров.

Исправлены семь воспроизводимых ошибок: отменённый запрос мешал откату Xray после ошибки сохранения; сбой подготовки обновления геоданных блокировал исправный текущий набор; перенаправленный промежуточный каталог установки мог затронуть чужие файлы; новый обновлятор мог потерять закреплённый адрес выпусков; удаление разрушало действующую блокировку; повтор актуальной установки требовал место второго bundle; активный универсальный слот мешал выбрать появившуюся точную цель. Ошибки сети, подписи и несовпадение цели не разрешают fallback. Защита от понижения версии сохранена.

После публикации **17/17 сочетаний** прошли чистую установку через настоящую команду GitHub в QEMU: выбор точной цели, проверка восьми файлов, меню, ручное отключение и включение, настоящая перезагрузка с работающей службой и удаление с сохранением посторонних настроек. Все 327 файлов GitHub сверены по именам, размерам и SHA-256. Регрессионные проверки, race, vet и проверка зависимостей прошли до публикации; откат дополнительно проверен в шести сценариях с настоящими procd и Xray.

Если установлен универсальный v1.2.8, для непосредственного перехода на точный v1.2.9 повторите новую команду из [README](../README.md). Этот переход отдельно прошёл девять проверок: сохранены HWID, язык, ручное отключение и предыдущий слот, проверены перезагрузка в отключённом состоянии, включение из меню и автозапуск после второй перезагрузки. Старое меню v1.2.8 при обычном обновлении продолжает выбирать универсальный пакет своего семейства. Если оно уже установило универсальный v1.2.9, переход на точный пакет возможен со следующим более новым выпуском. Равная версия повторно не устанавливается.

Xray 26.3.27, геоданные и init-файлы побайтово сохранены из подписанного v1.2.8; соответствующий исходный архив Xray и лицензии включены. Проверки относятся к официальным виртуальным образам с 512 МиБ RAM и корневым разделом 512 МиБ, без живой подписки. Эти результаты не подтверждают работу каждой физической модели роутера и каждого VPN-сервера.
