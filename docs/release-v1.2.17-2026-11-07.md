# LuchWrt v1.2.17

7 ноября 2026 года.

Выпуск содержит 18 точных и восемь универсальных подписанных комплектов,
общий установочный скрипт и архив соответствующих исходников Xray.
Все 340 файлов сверены по именам, размерам и SHA-256.
Ключ подписи сохранён.

## Изменения

- Выключенный профиль GeoSite/GeoIP проверяется при изменении и сохраняется
  без перезапуска работающего Xray.
- Раннее общее правило подписки, включая список TCP/UDP, вызывает явный
  отказ при включении дополнения, которое оно перекрывает.
- Конфигурация подписки отклоняется при активном webhook маршрутизации,
  записи ключей TLS/REALITY или чтении локальных сертификатов и ключей.
- Клиент, установщик и Xray пересобраны на Go 1.27.3. Обновлены сетевые
  зависимости Xray. Обновлены Brotli до 1.2.7 и compress до 1.20.2.
  Исправление проверки имени сервера при закреплении CA-сертификата
  перенесено из upstream commit 64fada32b5b9e6ae064a038fa0e4e2b766499bd5.
  Регрессионный тест отклоняет пустое и неверное имя сервера и принимает
  корректное. При сканировании бинарника старая версия основного модуля
  Xray по-прежнему отмечается как GO-2026-6651. Соответствующий код исправлен
  в архиве исходников этого выпуска, а отчёт о сканировании хранится вместе
  с доказательствами переноса исправления.
- Выбор apk/opkg согласован во всех этапах начальной установки.
  Добавлен точный пакет OpenWrt 25.12.6 ARM64.
- Для 32-битного x86 сохранён softfloat, для ARM — прежние уровни инструкций,
  для MIPS — порядок байтов и softfloat.

## Проверки

Кандидат прошёл по 12 сквозных сценариев на OpenWrt 21.02.7 x86-64/fw3
и 25.12.6 ARM64/fw4, по 256 МиБ RAM. Проверены подписанная установка,
LAN TCP/UDP/DNS по IPv4/IPv6 через VLESS/TLS, импорт и обновление DAT,
перезагрузка, нехватка места, удаление и откат профиля после отказа связи.
Бинарники клиента и Xray в выпуске побайтово совпадают с повторно испытанными.
Прошли тесты Go с проверкой гонок, go vet и 101 тест Python.

Протокол публичной установки и обновления приведён в
[машиночитаемом отчёте](compatibility/2026-11-07-v1.2.17.json).
Подробности исправлений находятся в [аудите](DEEP_AUDIT_2026-11-05.md).

Испытания выполнены в QEMU. Физические устройства, аппаратное ускорение
и полный цикл на остальных целевых прошивках требуют отдельных испытаний.
Исторические результаты установки сохраняют свои версии в
[таблице совместимости](COMPATIBILITY_GUIDE.md).
