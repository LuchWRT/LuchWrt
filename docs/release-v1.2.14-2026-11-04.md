# LuchWrt v1.2.14

4 ноября 2026 года. Исправлены обновление списка локаций и смена локации после изменения формата подписки. Клиент принимает штатную секцию `observatory` вместе с прежними настройками Xray. При неудачном чтении подписки после перезагрузки показывается ошибка ответа сервера. [Документация Xray](https://xtls.github.io/en/config/observatory.html).

Двухступенчатая схема loopback из текущей подписки проверяется до запуска. Для проверки VPN используется основной пул с проверенным резервным VPN-путём. Дополнительные GeoSite/GeoIP применяются на основной ступени после исходных правил этой ступени. Резервная ветвь использует исходную маршрутизацию.

На официальном OpenWrt 25.12.5 ARM64 с 256 МиБ RAM установлена опубликованная v1.2.13. После изменения ответа тестового сервера и перезагрузки воспроизвелись обе ошибки. Обновление до финального подписанного v1.2.14 прошло поверх сохранённых настроек. Пункты 4 и 3 возобновили работу с тем же HWID. Проверен трафик LAN через реальный Xray VLESS/TLS, в том числе переключение при отказе VPN-выходов. Пройдены все семь этапов сценария.

Комплектный Xray 26.3.27 принял 13 локаций свежего ответа подписки с активными GeoSite и GeoIP. Шесть локальных HTTP-сценариев подтвердили работу баз и приоритет исходного правила, включая второй проход через loopback. Проверки Go и `go vet` пройдены.

Опубликовано 25 подписанных комплектов для восьми семейств процессоров. Пересобран клиент. Установщик, Xray, штатные базы и файлы служб взяты из подписанных пакетов v1.2.13. Имена, размеры и контрольные суммы всех 327 файлов совпали с проверенной сборкой. Установка с GitHub на чистом официальном OpenWrt 24.10.8 x86-64 прошла все семь этапов, включая перезагрузку и удаление.

Для обновления выберите «Установить новую версию». После установки проверьте пункт 4 «Обновить локации и проверить VPN». Для выбора другой локации используйте пункт 3. [Команда установки](../README.md#установка).
