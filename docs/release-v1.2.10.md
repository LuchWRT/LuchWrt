# LuchWrt v1.2.10

Выпуск улучшает надёжность установки, фоновой работы и восстановления настроек. Сохранены 17 точных подписанных пакетов OpenWrt и восемь универсальных семейств процессоров. Одна команда выбирает подходящий пакет автоматически.

1. Обновление записывает журнал переключения и проверяет оба слота перед аварийным восстановлением. Остановка для обновления сохраняет автозапуск; ручное отключение сохраняется после перезагрузки.
2. Клиент проверяет размер будущего состояния до изменения подключения. При ошибке записи учитывает фактический результат сохранения и проверяет прежний VPN перед возвратом перехвата LAN. Отказ подписки блокирует повторный запуск отозванной конфигурации даже при заполненном накопителе.
3. Обход длинного списка локаций ограничен по времени и размеру. Неизменившееся обновление подписки сохраняет продвижение; ручной выбор начинает новый обход.
4. Сетевые адаптеры fw3/fw4 обновляют собственные правила при изменении LAN и IPv6. Неизвестные или изменённые посторонним кодом правила сохраняются с сообщением о конфликте.
5. Неизменная успешная проверка не переписывает настройки. Ограниченная диагностика хранит причины и сроки проверок без ссылки подписки, HWID и конфигурации Xray.
6. Добавлен стенд полной цепочки: обычный подписанный клиент, меню, подписка через TLS, Xray VLESS/TLS и отдельный LAN-клиент. Результаты установки, сетевых испытаний и длительной работы учитываются раздельно.
7. Добавлены закрытая резервная копия, подготовка настроек к OpenWrt sysupgrade и явное восстановление повреждённой установки той же версии. Копия исключает кеш ключей Xray; после восстановления требуется свежая подписка. Настройки из штатного sysupgrade проверяются до ужесточения прав каталога и повторной установки.

При постоянной записи на Linux клиент дополнительно подтверждает метаданные файловой системы. Это исправляет воспроизведённую потерю метаданных выделения места на ext4 без журнала после отключения виртуальной машины. Ошибки сохранения остаются видимыми пользователю.

Xray 26.3.27 и геоданные побайтово сохранены из подписанного v1.2.9. Luch, установщик и init-файлы собраны из нового зафиксированного снимка. Подписи всех 25 комплектов и их указателей проверены до загрузки; выпуск содержит 327 файлов. Исходный архив Xray и лицензии сохранены.
