# Помощь с установкой

Копируйте весь блок установки кнопкой копирования в [README](../README.md#установка) либо из [текста без форматирования](install-command-v1.2.13.txt). Вставляйте его в SSH-терминал роутера от имени `root`.

При пересылке через мессенджер используйте блок кода или отправляйте ссылку на README. Обычный форматированный текст может потерять `||`, получить неразрывные пробелы, лишние обратные слеши или Markdown-ссылку вместо адреса. Такая копия уже не является исходной командой; не исправляйте её вручную по частям.

Установщик сообщает выполняемый этап. Ожидание обновления системных пакетов или загрузки ещё не означает ошибку. Если появилась строка `Luch VPN: ...` с отказом, сохраните её и указанный путь к журналу `/tmp/luch-...`. Для разбора нужны точный текст отказа, модель роутера и версия OpenWrt. Повторяйте исходную команду только после завершения предыдущей попытки.

HTTPS, подписи пакетов и контрольные суммы отключать не нужно. При нехватке постоянного места установщик сообщает об этом отдельно; объём RAM не заменяет место для программы.
