# Установка во внутреннюю память и на внешний накопитель

С v1.2.18 клиент и установщик используют один исполняемый файл с двумя именами.
Все функции, Xray, базы и проверка подписей сохранены. На ARM64 постоянный
комплект занимает примерно **36,7 МиБ** вместо 43,1 МиБ. Для первой сетевой
установки нужно примерно **53 МиБ свободного места**, включая прежний резерв
16 МиБ. Для других процессоров порог составляет примерно 54–59 МиБ;
установщик рассчитывает его по подписанным размерам конкретного комплекта.
Объём установленных системных пакетов и дополнительных DAT-баз зависит от
прошивки и настроек. Проверка места повторяется после установки зависимостей.

## Внутренняя память роутера

Выполните [актуальную команду установки](../README.md#установка). Отдельная
«облегчённая» версия не нужна. Установщик сохраняет программу во внутреннем
постоянном разделе, проверяет свободное место и подписи. После установки
откройте меню командой `luch`.

При переходе со старого выпуска используйте актуальную команду из README:
прежний установщик ещё не умеет хранить клиент и установщик одним файлом.
Настройки и HWID сохраняются. Обновлению нужно место для новой версии,
пока прежняя остаётся доступной для отката; небольшой остаток после первой
установки сам по себе не гарантирует достаточного места для обновления.

## Внешний накопитель: extroot

Поддерживаемый способ — предварительно настроенный **extroot OpenWrt**.
Он переносит весь записываемый слой `/overlay` на постоянный внешний раздел.
После этого та же команда установки размещает на нём программу и настройки;
ручное изменение путей Luch не требуется. Простое подключение диска в `/mnt`
или перенос отдельных папок символическими ссылками не включает этот режим.

1. Убедитесь, что роутер поддерживает нужный накопитель и драйверы. Сохраните
   резервную копию настроек OpenWrt; если Luch уже установлен — также его
   приватную резервную копию через меню.
2. Подготовьте отдельный пустой раздел ext4. Следуйте
   [инструкции extroot для OpenWrt](https://openwrt.org/docs/guide-user/additional-software/extroot_configuration):
   установите `block-mount`, поддержку ext4 и драйвер контроллера/накопителя
   из репозитория **своей версии прошивки**. Пакеты ядра от другой сборки
   использовать нельзя. Выбор и форматирование раздела стирают его данные.
3. Настройте постоянное монтирование раздела как `/overlay` по UUID,
   скопируйте существующий overlay по инструкции OpenWrt и перезагрузите
   роутер. Это настройка системы, установщик Luch сам диски не форматирует.
4. До установки убедитесь, что extroot действительно включился:

   ```sh
   block info
   mount | grep ' /overlay '
   df -h /overlay /etc /usr/libexec
   ```

   В `/overlay` должен быть внешний ext4-раздел, а свободное место `/etc`
   и `/usr/libexec` должно соответствовать внешнему накопителю. Если
   по-прежнему видно свободное место внутренней flash, сначала исправьте
   extroot. На прошивках без стандартного SquashFS/overlay схема отличается.
5. Выполните [актуальную команду установки](../README.md#установка).
   Проверьте `luch doctor`, подключение через меню и автозапуск после
   перезагрузки с подключённым накопителем.

Накопитель становится частью корневой системы: не извлекайте его во время
работы. Поведение при загрузке без него зависит от содержимого внутреннего
overlay. В испытанном сценарии Luch устанавливался после включения extroot:
без диска загружалась внутренняя система с обычным доступом LAN в Интернет,
после возвращения диска и перезагрузки восстанавливались прежние HWID и VPN.
Это не гарантирует идентичного поведения у системы, перенесённой с уже
установленным клиентом. После обновления самой прошивки extroot и совместимые
драйверы необходимо проверить заново по инструкции OpenWrt.

## Xiaomi Mi Router AX3000T

По [спецификации Xiaomi](https://www.mi.com/uk/product/xiaomi-router-ax3000t/specs/)
у AX3000T нет штатного USB-порта, поэтому обычная USB-флешка для него не
является доступным способом расширения памяти. Оптимизация v1.2.18 рассчитана
на установку в оставшуюся внутреннюю память без урезания функций.

Установка при ограничении в 57 МиБ проверена на официальном виртуальном
образе OpenWrt 25.12.4 ARM64. Это проверка программного сценария и объёма,
а не испытание физического AX3000T: его flash, ядро, Wi-Fi и аппаратное
ускорение требуют отдельного прогона на устройстве.
