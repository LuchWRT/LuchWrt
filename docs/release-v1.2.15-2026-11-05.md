# LuchWrt v1.2.15

5 ноября 2026 года выпущены исправления углублённого аудита. Клиент проверяет запасные выходы VPN, повторно подтверждает подписку при выборе локации и восстанавливает перехват LAN после неудачного запуска только после проверки прежнего VPN. Настройки GeoSite/GeoIP и работающий Xray остаются согласованы при частичном сбое записи. [Найденные проблемы и исправления](AUDIT_2026-11-05.md).

Подписано 25 комплектов для восьми семейств процессоров. Пересобран клиент. Установщик, Xray, штатные базы, скрипты служб и лицензии сверены с подписанным v1.2.14. Имена, размеры и SHA-256 всех 327 файлов совпали в черновике и в опубликованном выпуске.

В рабочем сценарии пройдены семь этапов на OpenWrt 21.02.7 x86-64 с fw3 и 25.12.5 ARM64 с fw4. Проверены меню, GeoSite, обработка отзыва, восстановление связи и LAN-трафик через Xray. На стенде использовался отдельный ключ. Клиент и шесть файлов поддержки, включая Xray, побайтно совпали с производственной сборкой.

После публикации точная команда из README выполнена на двух чистых официальных образах.

| OpenWrt | Архитектура | Результат установки с GitHub |
| --- | --- | --- |
| 21.02.7 | x86-64 | 7 из 7 этапов |
| 25.12.5 | ARM64 | 7 из 7 этапов |

В обоих прогонах проверены реальная загрузка, совпадение восьми установленных файлов, меню, Xray, перезагрузка с автозапуском и удаление с сохранением посторонних настроек. Результаты относятся к этим виртуальным роутерам и сценариям.
